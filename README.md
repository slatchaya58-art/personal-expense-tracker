Personal Expense Tracker

About the Project

A simple Python project to record and analyze daily expenses.

Features

- Add new expenses
- View all expenses
- Calculate total spending
- View category-wise expenses
- Calculate monthly expenses
- Visualize expenses using a bar chart

Technologies Used

- Python
- CSV
- Matplotlib

Installation

Install Matplotlib using:

"python -m pip install matplotlib"

How to Run

1. Keep "expense_tracker.py" and "expenses.csv" in the same folder.
2. Open the terminal in that folder.
3. Run:

"python expense_tracker.py"

Project Status

Beginner-level Python project for tracking and analyzing personal expenses.
