Personal Expense Tracker

About the Project

A Python-based application to record daily expenses and analyze personal spending.

Features

- Add new expenses
- View all recorded expenses
- Calculate total spending
- Analyze category-wise expenses
- Calculate monthly expenses
- Visualize category-wise spending using a bar chart

Technologies Used

- Python
- CSV
- Matplotlib

Project Structure

personal-expense-tracker/
├── expense_tracker.py
├── expenses.csv
└── README.md

Installation

Install the required library:

python -m pip install matplotlib

How to Run

1. Download or clone this repository.
2. Keep "expense_tracker.py" and "expenses.csv" in the same folder.
3. Open the folder in VS Code.
4. Run the following command in the terminal:

python expense_tracker.py

Sample Data

The CSV file stores:

- Date
- Category
- Amount
- Note
